## 2. Config files

### Paths (Unix), high → low merge order after reverse of project walk

From `internal/config/load.go` `lookupConfigs` + `GlobalConfig`:

| Priority group | Path |
| --- | --- |
| System (lowest) | `/etc/crush/crush.json` (`config_unix.go`) |
| User JSON | `$XDG_CONFIG_HOME/crush/crush.json` (default `~/.config/crush/crush.json`) |
| User shell | same dir `crushrc` |
| Machine state JSON | `$XDG_DATA_HOME/crush/crush.json` (default `~/.local/share/crush/crush.json`) — **state, do not emit** |
| Project (git-root bounded) | `./.crushrc`, `./crushrc`, `./.crush.json`, `./crush.json` |
| Workspace overlay (highest) | `<data_directory>/crush.json` (default `./.crush/crush.json`) |

Within one directory, after reverse+merge: `.crushrc` > `crushrc` > `.crush.json` > `crush.json`.

Env overrides:

- `CRUSH_GLOBAL_CONFIG` — directory containing `crush.json` (and sibling `crushrc`)
- `CRUSH_GLOBAL_DATA` — directory containing machine-state `crush.json`
- `XDG_CONFIG_HOME` / `XDG_DATA_HOME` — standard XDG
- `CRUSH_CACHE_DIR`
- `CRUSH_SKILLS_DIR`
- `CRUSH_DISABLE_PROVIDER_AUTO_UPDATE`
- `CRUSH_DISABLE_DEFAULT_PROVIDERS`
- `CRUSH_DISABLE_METRICS` / `DO_NOT_TRACK`
- `CATWALK_URL` — provider catalog

`crush dirs` on this machine: `/Users/dengqi/.config/crush`, `/Users/dengqi/.local/share/crush`, `/etc/crush`.

**agentcfg should emit** `~/.config/crush/crush.json` (user JSON). Optional project overlay: `./crush.json` or `./.crush.json`. Do not write data-dir state.

### Format

- **Strict JSON**, UTF-8. Loader: `json.Valid(data)` then `json.Unmarshal` (`load.go`). **Not JSONC**: comments and trailing commas fail `json.Valid`.
- Docs `docs/config/README.md` show a `jsonc` example with trailing commas — **docs lie; loader is RFC 7159 JSON**.
- Optional `"$schema": "https://charm.land/crush.json"`.
- Schema file in repo: `schema.json` (`$id`: `https://github.com/charmbracelet/crush/internal/config/config`). Generated by hidden `crush schema`.
- Root `additionalProperties: false` in schema; Go `json.Unmarshal` **ignores unknown keys** (schema is advisory).
- `crushrc` is Bash (Crush builtins). JSON still merges with it. For a compiler, emit JSON.

### Trusted code

`api_key`, URLs, MCP command/args/env/headers, extra_headers, top-level `env` values all run through **shell expansion** (`$VAR`, `${VAR}`, `${VAR:-default}`, `${VAR:?msg}`, `$(command)`). Config is equivalent to executing a shell.

## 3. Custom providers

Root key: **`providers` object**, keyed by provider id (not an array).

```json
{
  "$schema": "https://charm.land/crush.json",
  "providers": {
    "<id>": {
      "id": "<id>",
      "name": "Display Name",
      "type": "openai-compat",
      "base_url": "https://api.example.com/v1",
      "api_key": "$EXAMPLE_API_KEY",
      "extra_headers": { "X-Custom": "$EXAMPLE_HEADER" },
      "extra_body": {},
      "disable": false,
      "discover_models": false,
      "models": []
    }
  }
}
```

### ProviderConfig keys (schema + `internal/config/config.go`)

| JSON key | Type | Notes |
| --- | --- | --- |
| `id` | string | Optional in object; loader **overwrites with map key** |
| `name` | string | Defaults to id |
| `base_url` | uri string | Required for custom providers; empty → provider **skipped** |
| `type` | enum | Default in **code** for custom providers: `openai-compat` (comment in load.go wrongly says "OpenAI"). Schema default tag says `"openai"` — **code wins**. |
| `api_key` | string | Shell-expanded. Example in schema: `"$OPENAI_API_KEY"`. **No `api_key_env` field.** Empty is allowed for local providers. |
| `oauth` | object | OAuth token (runtime; do not emit) |
| `disable` | bool | default false |
| `system_prompt_prefix` | string | |
| `extra_headers` | `{[k]: string}` | Shell-expanded. Empty resolved value → header **dropped**. |
| `extra_body` | object | **Not** shell-expanded. OpenAI-compat only. |
| `provider_options` | object | |
| `aws_auth_refresh` | string | Bedrock only |
| `flat_rate` | bool | |
| `discover_models` | bool | default true. Empty models list auto-discovers unless false. |
| `models` | array of Model | Required in practice: empty after discovery → provider skipped |

**No** `api_type`, `api`, `api_key_env`, `headers` (use `extra_headers`), `context_window` at provider level.

### `type` enum (live schema, `internal/cmd/schema.go`)

Catwalk `KnownProviderTypes()`:

- `openai` — **OpenAI Responses API** (`openai.WithUseResponsesAPI()` in `coordinator.go`)
- `openai-compat` — OpenAI-compatible **Chat Completions** (`openaicompat.New`)
- `openrouter`
- `vercel`
- `anthropic` — Anthropic Messages
- `google`
- `azure` — also forces Responses API
- `bedrock`
- `google-vertex`

Plus Crush-local:

- `hyper` (Charm Hyper)
- discover enrichers: `litellm`, `llamacpp`, `lmstudio`, `ollama`, `omlx` (all implemented as openai-compat)

Unsupported type → custom provider **skipped with slog.Warn**, not a hard error.

### Protocol implication (critical for IR)

| Crush `type` | Wire protocol |
| --- | --- |
| `openai` | OpenAI **Responses** (`/v1/responses`) |
| `openai-compat` (and ollama/litellm/…) | OpenAI **Chat Completions** |
| `anthropic` | Anthropic Messages (`x-api-key` unless key already `Bearer …`) |
| `google` / `google-vertex` | Gemini |
| `azure` | Azure OpenAI + Responses API |

README: use `openai` when proxying **through OpenAI**; use `openai-compat` for non-OpenAI OpenAI-compatible APIs.

### Model object (`catwalk.Model`)

Schema **required**: `id`, `name`, `cost_per_1m_in`, `cost_per_1m_out`, `cost_per_1m_in_cached`, `cost_per_1m_out_cached`, `context_window`, `default_max_tokens`, `can_reason`, `supports_attachments`.

Go unmarshal does **not** enforce required; missing numbers become 0 / false. Emitter should still fill them (costs may be `0`).

| JSON key | Maps from |
| --- | --- |
| `id` | model id sent to API |
| `name` | display name |
| `context_window` | int |
| `default_max_tokens` | max output tokens |
| `can_reason` | bool |
| `reasoning_levels` | string[] optional |
| `default_reasoning_effort` | string optional |
| `supports_attachments` | **images** only (`SupportsImages bool \`json:"supports_attachments"\``) |
| `cost_per_1m_*` | four floats; no IR equivalent — emit `0` |
| `options` | temperature / top_p / top_k / penalties |

**No** native keys for: tool_calling, input/output modality lists, audio/video/pdf, `max_tokens` (that is on the *selected* model slot).

### Provider-level headers

Yes: `extra_headers` map[string]string. Values expand. Empty → omitted.

Anthropic thinking injects `anthropic-beta: interleaved-thinking-2025-05-14` at request time (`coordinator.go`).

## 4. Env handling

**No `api_key_env`.** Put the env name in `api_key` as a shell template:

- `$VOLC_API_KEY`
- `${VOLC_API_KEY}`
- `${VOLC_API_KEY:?set VOLC_API_KEY}` (fail loud if unset — recommended)

Interpolation (`internal/config/resolve.go` `NewShellVariableResolver`):

- `$VAR` / `${VAR}`
- `${VAR:-default}` / `${VAR:+alt}` / `${VAR:?msg}`
- `$(command)` (hard error on failure)
- Unset vars → empty string (bash-like) unless `:?`
- Lone `"$"` is a load error
- Timeout 5 minutes per expansion

Where expansion runs:

- provider `api_key`, `base_url`, `extra_headers` values
- MCP `command`, `args`, `env` values, `url`, `headers`, oauth client fields
- top-level `env` values (then `os.Setenv`)
- **not** `extra_body` strings

Top-level `"env": { "AWS_PROFILE": "x" }` is applied at startup **before** providers (`applyEnv`).

`PushPopCrushEnv`: any `CRUSH_<NAME>` is copied onto `<NAME>` for the provider-config pass (so `CRUSH_OPENAI_API_KEY` can feed `$OPENAI_API_KEY`).

Built-in provider env names (README): `HYPER_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, AWS/Azure/Vertex vars, etc. Custom providers do not auto-read a conventional env unless the `api_key` template references it.

## 5. Defaults (selected models)

Not a single `default_model`. Two slots under **`models` object**:

```json
"models": {
  "large": { "model": "<id>", "provider": "<provider-id>" },
  "small": { "model": "<id>", "provider": "<provider-id>" }
}
```

SelectedModel required: `model`, `provider`. Optional: `reasoning_effort` (`low|medium|high`), `think` (bool, Anthropic), `max_tokens` (max 200000), `temperature` (0–1), `top_p`, `top_k`, `frequency_penalty`, `presence_penalty`, `provider_options`.

If unset, Crush picks from Catwalk catalog order, else first enabled custom provider / first model (`defaultModelSelection` in `load.go`). Invalid configured pair **silently falls back** to that default (`LargeFallback` / `SmallFallback`).

Coder agent uses **large**. Task agent also uses **large** (read-only tools). There is no `CRUSH_MODEL` env for selection.

IR `defaults.model` `"provider/model"` → set **both** `models.large` and `models.small` to that pair (Crush requires both slots in practice; user configs typically pin both).

## 6. MCP

Root key: **`mcp` object** (not array), keyed by server name. Schema `$defs.MCPs` = `additionalProperties: MCPConfig`.

```json
"mcp": {
  "<name>": {
    "type": "stdio",
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"],
    "env": { "FOO": "$FOO" },
    "timeout": 15,
    "disabled": false
  },
  "github": {
    "type": "http",
    "url": "https://api.github.com/mcp/",
    "headers": { "Authorization": "Bearer $GITHUB_TOKEN" },
    "timeout": 10
  }
}
```

### MCPConfig keys

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `type` | `stdio` \| `sse` \| `http` | `stdio` | **required** in schema |
| `command` | string | | stdio only; empty → runtime error `mcp stdio config requires a non-empty 'command' field` |
| `args` | string[] | | expanded per element |
| `env` | `{[k]: string}` | | expanded; prepended onto `os.Environ()` |
| `url` | uri | | http/sse; empty → runtime error |
| `headers` | `{[k]: string}` | | http/sse; empty resolved value omitted |
| `disabled` | bool | false | **not** `enabled` |
| `disabled_tools` / `enabled_tools` | string[] | | |
| `timeout` | int **seconds** | 10 (30 if oauth) | not milliseconds |
| `sessionless` | bool | auto | |
| `oauth`, `oauth_client_id`, `oauth_client_secret`, `oauth_callback_port` | | http (sse has a wrapper) |

**No** `name` inside the object (name is the map key). **No** `cwd` / working directory: stdio `exec.CommandContext` does not set `cmd.Dir` (`internal/agent/tools/mcp/init.go` `createTransport`). **No** `${VAR}` special syntax beyond the shell expander (so `${VAR}` works).

IR `enabled: false` → `disabled: true`. IR `enabled: true` / omitted → omit `disabled` or `false`.

## 7. IR mapping

IR types: `internal/ir/types.go` (this repo).

### providers[]

| IR | Crush | Rule |
| --- | --- | --- |
| `providers[].id` | `providers` map key **and** `id` | must be unique JSON object key |
| `name` | `providers.<id>.name` | fallback to id |
| `base_url` | `base_url` | required; reject empty |
| `protocol: openai-completions` | `"type": "openai-compat"` | Chat Completions |
| `protocol: openai-responses` | `"type": "openai"` | Responses API. **Warn/reject if base_url is not OpenAI or a known Responses proxy** — Crush `type=openai` always calls `WithUseResponsesAPI()`. A generic OpenAI-compat gateway that only implements `/v1/chat/completions` will break. Prefer reject unless user intends Responses. |
| `protocol: anthropic-messages` | `"type": "anthropic"` | |
| `api_key_env` | `api_key`: `"${ENV:?set ENV}"` | no native env-name field |
| `headers[k].value` | `extra_headers[k]` = literal | |
| `headers[k].from_env` | `extra_headers[k]` = `"${ENV}"` | empty env → header dropped at load (Crush behavior) |
| `headers[k].bearer_from_env` | `extra_headers.Authorization` = `"Bearer ${ENV}"` | IR already restricts bearer to Authorization |
| `models[]` | `providers.<id>.models[]` | |

Always set `"discover_models": false` when emitting an explicit model list so Catwalk/discovery cannot merge unexpected models.

Always emit model required schema fields:

```json
{
  "id": "<ir.models[].id>",
  "name": "<ir.models[].name or id>",
  "cost_per_1m_in": 0,
  "cost_per_1m_out": 0,
  "cost_per_1m_in_cached": 0,
  "cost_per_1m_out_cached": 0,
  "context_window": <ir.context_window or omit-with-0>,
  "default_max_tokens": <ir.max_output_tokens or 0>,
  "can_reason": <ir.reasoning or false>,
  "supports_attachments": <true iff input contains image>
}
```

### models[] capability mapping

| IR | Crush | Validation |
| --- | --- | --- |
| `id` / `name` | `id` / `name` | required |
| `context_window` | `context_window` | if set, emit int |
| `max_output_tokens` | `default_max_tokens` | if set, emit int |
| `reasoning` | `can_reason` | map bool |
| `input` contains `image` | `supports_attachments: true` | |
| `input` contains `audio`/`video`/`pdf` | **none** | **reject** (Crush only has image attachments) |
| `output` other than `text` (or empty) | **none** | **reject** non-text output |
| `tool_calling: false` | **none** | **reject** — Crush agents always expose tools; no per-model tool flag |
| `tool_calling: true` / omitted | (implicit) | ok |

### defaults

| IR | Crush |
| --- | --- |
| `defaults.model` `"provider/model"` | `models.large` and `models.small` = `{ "provider", "model" }` |

If `defaults` omitted: omit `models` and let Crush auto-select (or reject if agentcfg policy requires an explicit default).

### mcp[]

| IR | Crush |
| --- | --- |
| `id` | `mcp` map key |
| `transport: stdio` | `"type": "stdio"` |
| `transport: http` | `"type": "http"` |
| `command[]` | `command` = argv[0], `args` = argv[1:] | reject empty command for stdio |
| `url` | `url` | required for http |
| `headers` | `headers` | same value/from_env/bearer_from_env encoding as providers |
| `env` | `env` | HeaderValue encoding: `value` literal, `from_env` → `$VAR`. **reject `bearer_from_env` on env** if IR allows it — env values are not Authorization headers |
| `enabled` | invert to `disabled` | |
| `timeout_ms` | `timeout` seconds | convert; **reject** if not divisible by 1000 (or document ceil — prefer reject to avoid silent unit bugs) |
| `cwd` | **none** | **reject** — not representable |
| sse | Crush has `sse` | IR has no sse — do not emit |

### Must reject (never silently drop)

1. `protocol` outside `{openai-completions, openai-responses, anthropic-messages}`.
2. `openai-responses` targeting a completions-only `base_url` (non-OpenAI gateway) — Crush `type=openai` is Responses-only.
3. MCP `cwd` set.
4. MCP `timeout_ms` not convertible to integer seconds without remainder (policy).
5. Model `input` modalities other than `text`/`image`.
6. Model `output` modalities other than `text`.
7. `tool_calling: false`.
8. MCP transport other than `stdio`/`http`.
9. Header/env values that cannot be expressed as a single expanded string (Crush has no structured secret refs besides shell).
10. Duplicate provider or MCP ids (object keys collide).

### Safe to omit / default

- Model cost fields → `0`.
- `discover_models: false` when models listed.
- `name` defaulting to id.
- `disabled: false` omitted.
- `$schema` recommended.

### Suggested artifact

- Name: `crush`
- Format: JSON (strict)
- Path: `~/.config/crush/crush.json`
- Project optional: `./crush.json`
- Do **not** emit `~/.local/share/crush/crush.json`
- Do **not** emit `crushrc` unless a later target is added
